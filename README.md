# RZXXY Cinematic Developer Portfolio

A responsive, cinematic portfolio built with plain HTML, CSS, and JavaScript.

## Features
- Responsive desktop and mobile layout
- Cinematic dark theme with blue highlights
- Mobile navigation menu
- Project category filters
- Light/dark theme toggle
- Scroll reveal effects
- Sections for About, Projects, Skills, and Contact

## Run locally
Open `index.html` in a browser.

## Customize
- Update project cards and links to point to the real projects.
- Edit the skills and descriptions to match current experience.
- Review the website on mobile before sharing.

## Publish with GitHub Pages
1. Open repository **Settings**.
2. Select **Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then Save.
5. Wait for deployment to finish. The site URL should be `https://Ryzxxy8.github.io/personal-portfolio/`.
