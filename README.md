# RZXXY — Cinematic Developer Portfolio

A responsive, cinematic portfolio showcasing **RZXXY's** projects and learning journey across web development, Python, AI, and ethical cybersecurity.

**Live website:** https://rzxxy8.github.io/personal-portfolio/  
**GitHub profile:** https://github.com/Ryzxxy8

## Overview

Built with plain **HTML, CSS, and JavaScript**, this portfolio uses a dark cinematic interface, blue and cyan accents, responsive project cards, and lightweight browser-side interactions.

## Features

- Responsive layout for desktop and mobile
- Cinematic dark theme with blue/cyan highlights
- Mobile navigation menu
- Project cards with category filters
- Light/dark theme toggle
- Scroll-reveal effects
- About, Projects, Skills, and Contact sections
- No framework or build step required

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Inter)
- Unsplash-hosted background photography

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern browser.

No package installation or build command is required.

## Customize the portfolio

- **Projects:** Update the project cards in `index.html`, including their categories, descriptions, and destination links.
- **Appearance:** Edit `style.css` to adjust colors, spacing, typography, and imagery.
- **Interactions:** Edit `script.js` to change navigation, filtering, theme toggle, and scroll effects.
- **Profile details:** Review the About, Skills, and Contact sections before sharing the site publicly.

## Deploy with GitHub Pages

1. Open the repository on GitHub and go to **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/(root)`, then save.
4. Wait for the Pages deployment to complete.
5. Visit https://rzxxy8.github.io/personal-portfolio/.
